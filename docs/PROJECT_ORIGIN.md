# Project provenance

This repository is an **independently implemented learning backend**, started in November 2026,
using the general idea of an event-management app previously developed in a WBS Coding School team.

The original WBS/team project is NOT claimed as solely authored by Jan Ninh.

- Team frontend: https://github.com/DariaKozlova-web/events-frontend
- Team backend mirror: https://github.com/DariaKozlova-web/events-backend
- WBS-provided backend: https://github.com/WebDev-WBSCodingSchool/events-api

This repository's implementation is new. It does not copy source files from the team or WBS backend.
It deliberately uses direct parameterized SQLite queries to make relational database work inspectable.

Development style: AI-assisted collaboration with explicit review, testing and user ownership.
Claims of individual responsibility should reflect the actual reviewed, tested changes and not
merely the account to which commits were pushed.
